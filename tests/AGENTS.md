# Проверки По Зонам

- frontend/: Streamlit AppTest через корневой app.py, события и состояние сессии.
- backend/: операции application, копирование входов, provenance и изоляция поставщиков.
- test_partner.py: Backend, синтетические схемы IEK/Systeme.
- test_acceptance.py: Logic, причинные сценарии M1-M5/T1-T12.
- test_edges.py: совместная зона Backend/Logic; менять только тесты своей фичи.
- test_workflow.py: интегратор, расчёт и сквозной импорт/утверждение/экспорт без UI.
- conftest.py: общий контракт синтетических фикстур; сохранять совместимость.

Тестировать поведение, а не наличие заголовков или имён файлов. Новые независимые
проверки помещать в отдельный файл своей зоны, чтобы уменьшить конфликты веток.
Полная проверка перед объединением: python -m pytest -q и python scripts/smoke.py.
