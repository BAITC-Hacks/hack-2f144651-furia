# Источники перенесённых требований

Требования и аудит перенесены из публичного комплекта
[Ziyadin23/hackalem-ekt-agent-kit](https://github.com/Ziyadin23/hackalem-ekt-agent-kit).
Первоначальный перенос приложения ссылается на commit
`527b3004c01da60b0e63b10e0d2aaa3304dcd0ba`; при подготовке разделения задач
прочитана также версия `3d539074454f06061d8d82e624ddfcc58a46edc5`.

По описанию комплекта его автор изучил задание «Автоматизация формирования заказов
поставщикам», разделы 5–6 положения HackAlem AI и архивы IEK/Systeme Electric
(12 XLSX / 14 листов). Это происхождение исходного аудита, а не заявление о
проверке оригинальных файлов текущей реализацией.

Оригиналы и закрытые ссылки в официальный repo не добавлены. Для проверки
партнёрского импорта команда передаёт разрешённые локальные пути DATA/REVIEWER.
Без файлов используйте только явно синтетические макеты и сохраняйте ограничение.
