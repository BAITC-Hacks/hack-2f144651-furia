### Контракт и ограничения

- Python API, зависимости и состав проверок не менялись.
- **Блокирует:** billing lock остаётся внешним блокером удалённой приёмки;
  изменения workflow не устраняют его. Блокирующих дефектов согласованного diff нет.
- **Важно:** ручной запуск при действующей блокировке также может дать failure;
  старые красные результаты останутся. Новые push/PR автоматически не проверяются.
- **Можно отложить:** после разблокировки владелец запускает workflow вручную;
  после успешного прогона интегратор возвращает push/main и pull_request.
