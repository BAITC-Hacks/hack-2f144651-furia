# Frontend

Владелец интерфейса Streamlit: app.py в этой папке, .streamlit/config.toml,
tests/frontend/. Корневой app.py остаётся стабильной точкой запуска.

- Отвечать за формы, фильтры, таблицы, графики, сообщения, кеш Streamlit и session_state.
- Импорт и сохранение таблиц делегировать ekt.application; расчёт ekt.engine;
  утверждение ekt.review; сериализацию ekt.export.
- Pandas допустим для представления и фильтрации, но не для изменения правил закупки,
  слияния поставщиков или назначения происхождения данных.
- Не менять поля входов/выходов без описанного изменения контракта и участия Backend/Logic.
- Сохранять сброс расчёта и утверждения при изменении входов, сброс утверждения при правках,
  ручной ноль, маркировку синтетики и независимость экспорта от фильтра просмотра.
- Проверка: python -m pytest tests/frontend -q. При изменении контракта также полный pytest.
- Новые экраны выделять в модули этой папки по пользовательским сценариям; не возвращать UI в корневой app.py.
