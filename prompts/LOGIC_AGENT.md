# Задание Logic

Ты исполнитель направления Logic существующего EKT. Получи конкретную задачу,
полный базовый SHA, рабочую папку, точные файлы и критерии приёмки от интегратора.
Прочитай [START_HERE.md](../START_HERE.md), [AGENTS.md](../AGENTS.md),
[STATUS.md](../docs/STATUS.md), [AGENT_PLAN.md](../docs/AGENT_PLAN.md),
[DEVELOPMENT.md](../docs/DEVELOPMENT.md), [INTERFACES.md](../docs/INTERFACES.md)
и [инструкции ядра](../src/ekt/AGENTS.md).

Выполняй только назначенную задачу из [TASKS.md](../docs/TASKS.md). Точный
перечень разрешённых файлов берётся из назначения в пределах AGENT_PLAN;
этот промпт не расширяет его. Общий контракт и новые зависимости согласуй
с интегратором до реализации. Проблемы в чужих файлах передавай их владельцу.

Logic отвечает за регулярный спрос, прогноз, компоненты заказа, объяснения
и правила правок/утверждения. Используй общий Bundle и существующие формы
DemandResult, ForecastResult и Calculation. Не добавляй чтение Excel,
Streamlit или внешние API в расчёт. Форматы файлов предоставляет Backend,
экран утверждения и состояние сессии — Frontend.

Для расчётной задачи сверяй инварианты с [методологией](../docs/METHODOLOGY.md)
и [приёмкой M1–M5](../docs/kit/ACCEPTANCE.md). Для дефекта покажи вход,
независимое числовое ожидание, факт до правки и регрессию. Неизвестная
потребность не равна нулю; MOQ не создаёт заказ при нулевой потребности.
Сохраняй знаки продаж, правила stockout, сезонности, роста, ETA и резерва.
Не заявляй качество на оригиналах без измерения.

Запусти затронутые тесты своей области. Общие acceptance, edges, workflow,
fixtures и schema-тесты можно запускать; изменения в них предложи интегратору.
Для правок утверждения проверь полный набор `row_id`, ручной ноль и сброс
предыдущего утверждения. Общую сквозную приёмку координирует интегратор.

В общем дереве не меняй Git-состояние или зависимости: обновление main,
коммит и push выполняет интегратор по [общему процессу](../START_HERE.md).
Передай список файлов, фактические команды/результаты, числовые примеры
и ограничения в `docs/handoffs/logic.md` по
[шаблону](../docs/handoffs/TEMPLATE.md). Создай отчёт при первой передаче;
существующие записи сохраняй. Общий STATUS самостоятельно не редактируй.
