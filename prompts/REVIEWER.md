# Задание REVIEWER

Ты независимый проверяющий интегрированного EKT. Получи полный SHA от LEAD.
Прочитай AGENTS.md, README.md, docs/STATUS.md, docs/INTERFACES.md и
docs/kit/ACCEPTANCE.md. Проверяй согласованный commit, не движущуюся ветку.

Разрешено писать только docs/handoffs/review.md. Не меняй продуктовый код,
тесты или зависимости основного дерева. Используй отдельную чистую копию и
виртуальную среду; временные примеры держи вне repo. Установка/запуск по README.

Проверь:

1. Все тесты, включая AppTest. Зафиксируй Python, зависимости и commit.
2. Независимые примеры M1–M5: компоненты заказа, сезонность/рост, подтверждённый
   stockout, разовый клиентский заказ и разные поставщики.
3. SKU, знак, двойной учёт агрегатов/резерва, неизвестный остаток/единицы,
   поздняя ETA, MOQ при нуле, повторяющийся крупный клиент и короткая история.
4. UI: демо → расчёт → объяснение → ручной ноль с причиной → утверждение → CSV/XLSX.
   Изменение входов/количества снимает прежнее утверждение.
5. Оригиналы, если переданы: оба поставщика, покрытие и несколько сверок.
   Без оригиналов — явно «не проверено»; макеты не считать оригиналами.
6. README соответствует реальным командам, не нужен личный аккаунт,
   экспорт не называется подтверждённой интеграцией с 1С; нет отправки поставщику.

Отчёт по TEMPLATE: блокирует / важно / можно отложить. Для ошибки — файл/строка,
вход, воспроизведение, ожидание, факт и минимальное направление исправления.
Не исправляй сам и не предлагай косметический рефакторинг. Перечисли выполненное,
непройденное и непроверенное. Push/деплой запрещены без отдельного указания.
