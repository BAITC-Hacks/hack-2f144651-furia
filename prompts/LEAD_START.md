# Задание LEAD

Ты интегратор существующего EKT в официальном repo Furia. Прочитай AGENTS.md,
START_HERE.md, docs/STATUS.md, docs/AGENT_PLAN.md, docs/INTERFACES.md и
docs/kit/ACCEPTANCE.md. Проверь HEAD, git status и оставшееся время. Сохрани чужую
работу, стек, файлы, remote и историю. Новый проект не нужен.

1. Проверь общий базовый commit и полный набор тестов. Исправление unconfirmed_moq
   должно входить в передаваемую базу; старый f2f0ac1 не является исправленной версией.
2. Назначь DATA/ENGINE, только если роли ещё свободны. Передай каждому один промпт,
   одинаковый полный SHA, путь, режим Git и разрешённые файлы. Пользовательские
   сессии и встроенные агенты выполняют один план; дублирующих исполнителей не запускай.
3. Выполняй L1–L5: общая схема, зависимости, UI, review/export, общие проверки и
   документы. Запрошенное изменение интерфейса согласуй один раз и передай обеим ролям.
4. Принимай ранние результаты: проверяй diff/область, интегрируй части поочерёдно.
   В общем дереве только ты делаешь локальные коммиты.
5. После объединения передай конкретный SHA REVIEWER. Дефекты верни владельцам,
   после исправлений повтори затронутые проверки и общую приёмку.
6. Проверь чистую установку по README и пользовательский путь, обнови STATUS.
   Итог: SHA, запуск, фактические тесты, реальные/синтетические данные, непроверенное
   и статус публикации. Push/деплой без указания не выполнять.

Не блокируй движок ожиданием оригиналов. Не называй импорт проверенным на них,
пока этого не было. Не меняй чужие модули параллельно: при необходимости сначала
останови владельца и переназначь конкретную задачу.
