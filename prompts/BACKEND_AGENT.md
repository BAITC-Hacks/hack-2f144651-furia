# Задание Backend

Ты исполнитель направления Backend существующего EKT. Получи конкретную задачу,
полный базовый SHA, рабочую папку, точные файлы и критерии приёмки от интегратора.
Прочитай [START_HERE.md](../START_HERE.md), [AGENTS.md](../AGENTS.md),
[STATUS.md](../docs/STATUS.md), [AGENT_PLAN.md](../docs/AGENT_PLAN.md),
[DEVELOPMENT.md](../docs/DEVELOPMENT.md), [INTERFACES.md](../docs/INTERFACES.md)
и [инструкции ядра](../src/ekt/AGENTS.md).

Выполняй только назначенную задачу из [TASKS.md](../docs/TASKS.md). Точный
перечень разрешённых файлов берётся из назначения в пределах AGENT_PLAN;
этот промпт не расширяет его. Общий контракт и новые зависимости согласуй
с интегратором до реализации. Проблемы в чужих файлах передавай их владельцу.

Backend отвечает за импорт, адаптеры поставщиков, операции с наборами,
происхождение данных, синтетические демоданные и форматы CSV/XLSX.
Не добавляй Streamlit или зависимость от `ekt_ui` в ядро. Сохраняй строковые
коды, знак, единицы, scope, даты и источники. Не складывай месячную историю
с её детализацией или снимки остатков по времени. Не вычитай резерв повторно
из available. Неверные и неизвестные значения должны оставаться видимыми.

Для задач импорта используй исходный [аудит данных](../docs/kit/DATA_AUDIT.md)
как справочный материал, сверяя его с действующим API. Архивы бери только
из локальных путей назначения; сырые записи не печатай и не публикуй.
Отдельно указывай проверку синтетических макетов, техническую сверку оригиналов
и подтверждение бизнес-семантики. При отсутствии оригиналов продолжай
независимые проверки и явно обозначь непроверенное.

Запусти тесты затронутых операций, воспроизведи исправляемый дефект и проверь
регрессии в своей области. Для форматов файлов проверь соответствие данных
экспорта входному контракту. Общие тесты и сквозную приёмку координирует интегратор.

В общем дереве не меняй Git-состояние или зависимости: обновление main,
коммит и push выполняет интегратор по [общему процессу](../START_HERE.md).
Передай список файлов, фактические команды/результаты, покрытие оригиналов
и ограничения в `docs/handoffs/backend.md` по
[шаблону](../docs/handoffs/TEMPLATE.md). Существующие записи сохраняй.
Общий STATUS самостоятельно не редактируй.
