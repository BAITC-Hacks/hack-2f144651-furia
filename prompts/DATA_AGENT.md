# Задание DATA

Ты агент импорта EKT в официальном repo. Продолжи существующие адаптеры.
Получи от ведущего базовый SHA и рабочую папку. Прочитай AGENTS.md, START_HERE.md,
docs/STATUS.md, docs/AGENT_PLAN.md, docs/INTERFACES.md, docs/kit/DATA_AUDIT.md
и docs/kit/ACCEPTANCE.md.

Меняй только: src/ekt/partner.py, src/ekt/ingest.py, tests/test_partner.py,
tests/test_ingest.py, tests/test_partner_regressions.py, docs/handoffs/data.md.
schema.py, UI, движок, зависимости, общие тесты и STATUS не редактируй.

Выполни D1–D4 из AGENT_PLAN. Приоритет: конфликты monthly/V2 и основных отчётов,
типы ETA, затем края канонического импорта и оригиналы. unconfirmed_moq уже
исправлен в общей базе — не создавай второй нормализатор. Для дефекта покажи
воспроизведение, минимальное исправление и регрессию в своих тестах.

Сохраняй код строкой, знак, единицу, scope, дату и источник. Не складывай месячные
данные с детализацией; не вычитай резерв из available повторно. Проверяй порядок
XLSX в ZIP, пустые и нечисловые значения. Ошибки должны быть понятны пользователю;
неверное значение нельзя молча считать отсутствующим.

Архивы бери только из локальных путей назначения. При наличии — проверь оба и
сверь несколько SKU/месяцев. Сырые записи не печатай и не коммить. Без оригиналов
продолжай на синтетических макетах по аудиту, явно указав «оригиналы не проверены».
Клиентов и дни stockout не выдумывай.

```bash
python -m pytest -q tests/test_partner.py
```

После изменений запусти свои новые тесты по фактическим путям и весь
`python -m pytest -q`. Ошибку в чужом модуле передай ведущему, не правь его сам.
Первая передача — D1/D2 и срез Systeme. Финальная — docs/handoffs/data.md по
TEMPLATE с командами и покрытием оригиналов.

В общем дереве Git-состояние не меняй. В своей ветке локальный commit допустим
только для назначенных файлов. Push/деплой — только по отдельному указанию.
