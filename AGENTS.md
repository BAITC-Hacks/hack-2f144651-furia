# Локальная разработка EKT

Инструкции комплекта `Ziyadin23/hackalem-ekt-agent-kit`, commit
`527b3004c01da60b0e63b10e0d2aaa3304dcd0ba`, прочитаны. Требования и метод
сохранены в `docs/kit/`. Это отдельная локальная реализация по указанию пользователя.

- Разрешены локальные файлы, изолированные зависимости, запуск, проверки и локальные коммиты.
- Запрещены push, публикация, деплой, создание удалённых репозиториев и передача данных внешним сервисам без нового указания.
- Не менять существующие remotes, даты и историю коммитов. Этот репозиторий создаётся без remote.
- Отсутствие официального репозитория не блокирует реализацию. Это не подтверждение разрешения организаторов.
- Один агент отвечает за код; без дополнительных оркестраторов.
- Отделять синтетические данные, факты и ручные допущения. Числа считать локально.
- Сохранять строковые коды, единицы, область склада, происхождение и знаки продаж.
- Не дублировать месячные продажи детализацией, остатки снимками, резерв повторным вычетом.
- Обновлять docs/STATUS.md после этапов и сообщать только выполненные проверки.
