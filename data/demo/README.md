# Синтетическое демо

Демо воспроизводимо генерируется функцией `demo_bundle()` в `src/ekt/demo.py`, seed=42. Дата расчёта: 2026-09-22. Здесь нет исходных записей партнёра.

В интерфейсе можно загрузить демо одной кнопкой и скачать его как ZIP канонических CSV. Четыре товара покрывают сезонность, устойчивый рост, клиентский разовый заказ (1050 в трёх документах) и подтверждённый десятидневный stockout.
