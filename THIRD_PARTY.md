# Сторонние компоненты

Версии полного окружения зафиксированы в `requirements.lock`; сведения о лицензиях прочитаны из установленных package metadata.

| Компонент | Назначение | Лицензия |
|---|---|---|
| Python 3.12.14 | Runtime | PSF |
| Streamlit 1.64.0 | Локальный интерфейс / AppTest | Apache-2.0 |
| pandas 3.0.6 | Канонические таблицы и временные ряды | BSD-3-Clause |
| NumPy 2.5.3 | Числовые расчёты | BSD-3-Clause; wheel metadata также перечисляет 0BSD, MIT, Zlib, CC0-1.0 |
| openpyxl 3.1.5 | Чтение и экспорт XLSX | MIT |
| pytest 9.1.1 | Проверки | MIT |

Транзитивные пакеты поставляются с собственными лицензиями в дистрибутивах. Отдельное приложение не включает исходники этих библиотек.
