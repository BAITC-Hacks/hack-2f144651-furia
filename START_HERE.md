# Начало работы другого агента

Здесь уже есть приложение EKT. Не начинайте реализацию заново.
Исходный командный checkpoint — `f2f0ac1f77393b413464c5435971b42ed0d505c0`.
Для новой работы используйте более новый коммит, содержащий этот файл: в нём
исправлен тип `unconfirmed_moq` и добавлены правила передачи. Полный SHA даёт LEAD.

## Выберите назначенную роль

| Роль | Промпт | Результат |
|---|---|---|
| DATA | [DATA_AGENT.md](prompts/DATA_AGENT.md) | Проверенный импорт и покрытие данных |
| ENGINE | [ENGINE_AGENT.md](prompts/ENGINE_AGENT.md) | Проверенный расчёт и числовые регрессии |
| LEAD | [LEAD_START.md](prompts/LEAD_START.md) | Интегрированное приложение и общая приёмка |
| REVIEWER | [REVIEWER.md](prompts/REVIEWER.md) | Независимая проверка согласованного коммита |

Один агент получает одну роль. DATA и ENGINE работают параллельно, LEAD занимается
интеграцией; REVIEWER подключается после объединения. Если дали только ссылку без
роли, прочитайте инструкции и запросите назначение, чтобы не дублировать работу.

## Перед изменениями

```bash
git status --short --branch
git rev-parse HEAD
git remote -v
```

Прочитайте `AGENTS.md`, `docs/STATUS.md`, `docs/AGENT_PLAN.md`, `docs/INTERFACES.md`
и свой промпт. Сверьте SHA с ведущим. Не откатывайте существующий код к старому
checkpoint ради совпадения; сообщите расхождение. Установка — в [README](README.md).
После установки запустите `python -m pytest -q` Python из выбранной виртуальной
среды и зафиксируйте исходный результат.

## Сообщение для передачи агенту

Скопируйте блок, оставьте одну роль и заполните поля:

```text
Репозиторий: https://github.com/BAITC-Hacks/hack-2f144651-furia
Твоя роль: DATA / ENGINE / LEAD / REVIEWER.
Базовый commit: <полный SHA от ведущего>.
Рабочая папка: <путь к клону или worktree>.
Режим: <отдельная ветка/копия либо общее рабочее дерево>.
Владелец интеграции: <контакт или сессия ведущего>.
Архивы партнёра: <локальные пути либо «не переданы»>.
Прочитай START_HERE.md и свой промпт. Продолжай существующий код.
Меняй только разрешённые пути; результат передай по docs/handoffs/TEMPLATE.md.
Это сообщение не разрешает push или деплой.
```

В отдельной копии передавайте SHA доступного ведущему коммита либо `git format-patch`
и handoff: локальный SHA с другого компьютера сам по себе недоступен. В общем
дереве передавайте список файлов, не меняя Git-состояние.
